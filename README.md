# Матрицы комплексных чисел

Лабораторная работа: операции над матрицами комплексных чисел.

## Структура проекта
- `src/Complex.java` - класс комплексного числа (арифметика, модуль, строковый вывод)
- `src/Matrix.java` - класс матрицы (сложение, умножение, деление, транспонирование, определитель)
- `src/Main.java` - консольный интерфейс для ввода и выполнения операций

## Запуск
Компиляция:
```bash
javac src/*.java
```

Запуск:
```bash
java -cp src Main
```
